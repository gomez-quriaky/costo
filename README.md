# README COSTO

This is an algothrm that computes joint inversion in geology.


- To compile the code, do make costo.

        make costo

- To complile the code and the documentation (generated by doxigen), do make.

        make 
- To run the code, from costo_master folder location, go to your file input folder and then do ../costo

        cd /path/to/costo_master
        cd input_folder_case
        /../costo
